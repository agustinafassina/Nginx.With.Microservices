# ApiFour

Returns 2 random users in XML format.

- **Endpoint:** `GET /api/v4/random`
- **External API:** [Random Data API](https://random-data-api.com/)

## Run

```bash
dotnet run
```

Then open `https://localhost:5001/swagger` or call `https://localhost:5001/api/v4/random`.

To run it with Docker together with the other services, see the [main README](../README.md).
