# ApiThree

Returns geolocation data for the caller IP.

- **Endpoint:** `GET /api/v3/ipa`
- **External API:** [ipapi](https://ipapi.co/)

## Run

```bash
dotnet run
```

Then open `https://localhost:5001/swagger` or call `https://localhost:5001/api/v3/ipa`.

To run it with Docker together with the other services, see the [main README](../README.md).
