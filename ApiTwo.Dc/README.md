# ApiTwo

Returns the name and flag of every country.

- **Endpoint:** `GET /api/v2/countries`
- **External API:** [REST Countries](https://restcountries.com/)

## Run

```bash
dotnet run
```

Then open `https://localhost:5001/swagger` or call `https://localhost:5001/api/v2/countries`.

To run it with Docker together with the other services, see the [main README](../README.md).
